## Built: Dot Jot mockup (v0.1)
- Stack matches Habit Tracker: React 18 + Vite 5 + TypeScript + Tailwind 3 + lucide-react. No backend yet.
- Dark theme, bright colors, glow accents. Title "Dot Jot" with a glowing teal dot.
- Large glowing **+** button, fixed bottom-right (80px desktop / 64px mobile). Keyboard shortcut **N** also opens the jot field.
- Jot field opens at the **end** of the open-task list. Enter adds the task and keeps the field open; Esc closes; clicking away adds any typed text, then closes.
- New tasks are DOT teal `#34E3C8` (rgb 52, 227, 200 — main color of the DOT logo, which is a gradient).
- Each task: color dot → checkbox → text, all in the task's color. Clicking the dot opens the color picker (styled after the Project Tiles picker):
  14 swatches (2 rows of 7), big preview square (opens native color picker), hex field, Reset → teal.
  Swatches were brightened vs. the Project Tiles screenshot so they stay readable as text on dark.
- Checked tasks move to a **Done** section at the bottom, struck through and dimmed.
- Delete (×) appears on hover.
- Saved in browser localStorage (`dotjot.tasks.v1`) — no sync between devices.

## Decisions
- Color is chosen per task via its dot (not when adding), so quick entry stays fast.
- No category names for colors yet.
- Order: open tasks oldest → newest; done tasks most-recently-completed first.
